# 当前可用性边界

## 已实现的保护

- 注入前写入目标 profile。
- 目标进程选择与 PID 绑定。
- 运行时按 profile 选择适配器并验证 Minecraft、连接、监听器和关键方法。
- 不匹配的版本/加载器会失败关闭，不会进入错误的数据包构造路径。
- Hook/监听器停止仍沿用现有 drain/cleanup 流程。

## 当前生产路径

当前 native/server 和 native/world_snapshot 的生产数据包实现仍然是 1.20.1 风格。因此本次变更明确只允许：

- Minecraft 1.20.1 + Vanilla
- Minecraft 1.20.1 + Forge

其他版本或加载器会显示明确错误并拒绝启动，而不是伪装成兼容。

## 后续真正支持其他版本所需的代码

每个协议族必须实现独立的：

- 登录握手和登录完成包
- Netty pipeline 初始化/协议切换
- PacketFlow/Connection 状态
- 玩家列表、队伍、实体、区块和光照快照
- 传送确认和本地初始化确认
- 自定义 payload/模组登录通道策略
- B 端版本协商或明确的同版本要求

仅增加版本枚举、类名候选或加载器名称，不能完成这些工作。
